# Mini POS with QuickBooks Integration

A full-stack **Mini POS (Point of Sale) system** built with **ASP.NET Core + Angular + SQL Server** with seamless integration to **QuickBooks Online API** for accounting synchronization.

This project is designed for learning real-world **ERP + Accounting integration**, including OAuth 2.0, token management, and data synchronization with QuickBooks.

---

## 🚀 Features

### 🔐 Authentication
- JWT-based login system
- Role-based authorization (Admin/User)

### 👥 Customer Management
- Create / Update / Delete customers
- Sync customers with QuickBooks Online

### 📦 Product Management
- Product CRUD
- Price management
- QuickBooks item mapping

### 💰 Sales Module
- Create sales orders
- Add multiple products to sale
- Generate invoice

### ☁️ QuickBooks Integration
- OAuth 2.0 authentication
- Access & Refresh token handling
- Customer sync
- Invoice sync
- Payment sync
- Automatic token refresh

### 📊 Reports
- Sales report
- Customer report
- Profit overview
